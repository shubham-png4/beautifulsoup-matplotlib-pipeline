# 📊 Web Scraper & Data Visualizer Pipeline

A lightweight, automated Python pipeline that extracts data from a structured job listings platform, processes the records into an indexed data frame, and generates analytical visualizations.

## 🚀 Features

* **Targeted Web Scraping:** Uses `requests` with custom browser headers and `BeautifulSoup` to parse isolated structural elements out of HTML DOM trees.
* **Data Wrangling:** Normalizes raw textual fields, handles whitespace stripping, and splits location strings using `pandas`.
* **Analytical Visualization:** Aggregates categorical distributions to produce automated horizontal bar charts via `matplotlib`.

## 🛠️ Tech Stack & Dependencies

* **Language:** Python 3.x
* **HTTP Client:** `requests`
* **HTML Parser:** `beautifulsoup4`
* **Data Analytics:** `pandas`
* **Plotting Engine:** `matplotlib`
